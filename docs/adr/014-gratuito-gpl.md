# ADR-014 — Gratuito e GPL-3.0 (substitui o ADR-013)

- **Status:** Aceita
- **Data:** 2026-11-08

## Contexto

O ADR-013 previa repositório privado para venda. As SPECS e o Dossiê definiram o Pizza como gratuito e de código aberto, o que sustenta a promessa de transparência para cartórios.

## Decisão

O Pizza é gratuito, sem licença de uso nem conta, e o código é GPL-3.0. O repositório fica privado até os desvios da auditoria serem corrigidos e depois se torna público.

## Consequências

Quem recebe o programa pode auditar o código. Repositório público libera proteção de branch, varredura de segredos e CodeQL sem custo. O histórico inteiro fica público para sempre.

## Alternativas descartadas

- Repositório privado e venda (ADR-013).
