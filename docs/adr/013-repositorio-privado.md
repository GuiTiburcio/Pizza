# ADR-013 — Repositório privado até o v1.0

- **Status:** Aceita
- **Data:** 2026-11-07

## Contexto

O produto será vendido. Tornar o repositório público é possível a qualquer momento, mas o histórico inteiro fica visível e não dá para desfazer.

## Decisão

`GuiTiburcio/Pizza` começa privado. A decisão de abrir, e com qual licença, fica para a Fase 8 (v1.0).

## Consequências

Nada vaza antes da hora. No plano gratuito, repositório privado não tem regra de proteção de branch; o fluxo de PR é seguido por disciplina.

## Alternativas descartadas

- Público desde o início.
