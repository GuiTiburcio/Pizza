# Segurança

O Pizza lida com arquivos pessoais e de trabalho, muitas vezes sensíveis, de qualquer pessoa ou empresa que usa Windows. Por isso, relatos de vulnerabilidade têm prioridade.

## Como reportar

Use o **Private Vulnerability Reporting** do GitHub, na aba *Security* do repositório. Não abra issue pública para falhas de segurança.

Inclua, se possível: a versão, o que um atacante consegue fazer, em quais condições, e como reproduzir de forma segura com arquivos de teste.

## Prazos

| Etapa | Prazo |
| --- | --- |
| Primeira resposta | Até 72 h |
| Correção: explorada ativamente | Até 72 h |
| Correção: crítica | Até 7 dias |
| Correção: alta | Até 30 dias |
| Correção: média ou baixa | Próxima versão |

Depois da correção publicada, divulgamos um aviso de segurança, com crédito a quem reportou, se a pessoa quiser.

## Versões suportadas

Só a última versão menor recebe correções. O projeto ainda não tem versão publicada.
